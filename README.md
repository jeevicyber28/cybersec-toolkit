An advanced, defensive, and educational **all-in-one cybersecurity web platform and browser extension suite** designed for security engineers, analysts, developers, and students. It integrates machine learning transparency, zero-knowledge privacy audits, network socket probing, certificate grading, cryptographic forensics, and gamified phishing awareness into a single unified operations hub.

---

## 🌟 Complete All-in-One Security Arsenal

The toolkit is organized into 4 core defensive domains:

### 🎯 1. Threat & Phishing Defense
1. **Explainable ML URL Phishing Detector:**
   - Random Forest classifier trained on 16 structural, lexical, and behavioral URL signals.
   - Interactive horizontal bar charts explaining exactly which features drove the risk assessment.
   - Dedicated `/model-info` page generated by `train_model.py` detailing accuracy, precision, recall, F1-score, feature weights, and a confusion matrix.
2. **Email Journey & Header Forensics:**
   - Full parser for raw email headers and body payload.
   - Detects spoofing vectors via `From:` vs `Reply-To:` vs `Return-Path:` domain mismatches.
   - Evaluates cryptographic authentication (`SPF`, `DKIM`, and `DMARC` policies).
   - Interactive **MTA hop timeline** mapping chronological server hops, transit delays, and routing IPs.
   - Detects deceptive display links, social engineering urgency triggers, and dangerous attachment formats (`.exe`, `.scr`, `.zip.exe`).
3. **QR Code Phishing (Quishing) Scanner:**
   - Server-side OpenCV QR matrix decoding supporting uploaded images and noise-resistant adaptive thresholding.
   - Quarantines and displays the decoded destination payload before assessment with zero auto-redirection.
4. **Password & Breach Checker (Zero-Knowledge):**
   - Implements **k-Anonymity** via Web Crypto API: computes SHA-1 client-side in browser memory and queries only the first 5 hex characters against HaveIBeenPwned.
   - The plain password and remaining 35 hash characters **never leave the user's browser**.
   - Calculates Shannon entropy in bits, detects keyboard walks and sequential patterns, and estimates brute-force crack time under offline GPU vs online throttled conditions.
5. **Spot the Phish (Awareness Game):**
   - 10-round interactive quiz drawing from 40+ realistic scenarios (URLs, email snippets, and SMS messages).
   - Difficulty progression (`easy`, `medium`, `hard`) with detailed post-answer explanations.
   - Dynamic streak multiplier, high score tracking, and a tiered badge system (`Rookie`, `Defender`, `Phish Hunter`).
   - Playful CSS celebration animations on perfect scores with strict `prefers-reduced-motion` accessibility support.

### 🌐 2. Infrastructure, Network & Recon
6. **HTTP Security Headers & SSL/TLS Grader:**
   - Evaluates defensive response headers: `Content-Security-Policy` (CSP), `Strict-Transport-Security` (HSTS), `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, and `Permissions-Policy`.
   - Inspects server information leakage (`Server`, `X-Powered-By`).
   - Deep SSL/TLS certificate inspection: TLS version (1.2/1.3), cipher suites, issuer, subject CN, validity dates, days remaining with expiration alerts, and Subject Alternative Names (SANs).
   - Computes an overall hardening score with an **A+ to F** letter grade.
7. **Network Port & Service Hygiene Auditor:**
   - Safe, non-intrusive TCP socket handshake probing across critical standard ports: 21 (FTP), 22 (SSH), 23 (Telnet), 25 (SMTP), 53 (DNS), 80 (HTTP), 110 (POP3), 143 (IMAP), 443 (HTTPS), 445 (SMB), 3306 (MySQL), 3389 (RDP), 5432 (Postgres), 8080 (HTTP-Alt).
   - Measures response latency in milliseconds and flags dangerous unencrypted legacy protocols with defensive hardening notes.
8. **IP Threat Intelligence & DNS Reconnaissance:**
   - Input: IP address or hostname.
   - Range classification: Private RFC 1918, Loopback, Link-Local, Reserved, or Globally Routable Internet IP.
   - Reverse DNS (PTR) lookup.
   - Geo-IP and ASN enrichment: Country, city, region, ISP, ASN, and coordinates.
   - DNS record enumeration: Resolves A (IPv4) and AAAA (IPv6) records.
   - Flags suspicious markers (e.g. dynamic DNS tunnels commonly used in C2 campaigns).

### 🔐 3. Cryptography & Defense Engineering
9. **Cryptographic Hash Studio & Identifier:**
   - **Multi-Digest Generator:** Computes MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512, SHA3-256, and BLAKE2b checksums for text or binary file uploads.
   - **Automated Hash Identifier:** Analyzes unknown hash strings, prefix signatures (e.g. `$2a$`, `$argon2id$`, `$6$`), and bit lengths to identify candidate algorithms and known collision vulnerabilities.
   - **File Integrity Verifier:** Compares uploaded files against supplier release checksums to verify package authenticity and detect tampering.
10. **Cyber Defense Playbook & OWASP Top 10:**
    - Side-by-side vulnerable vs hardened code architectures across the OWASP Top 10 (Broken Access Control, Cryptographic Failures, SQL/Command Injection, SSRF, Misconfiguration).
    - SANS/NIST 4-phase Incident Response triage runbook and interactive operational checklists.
    - Essential Security CLI Command Palette (`openssl`, `curl`, `dig`, `tcpdump`, `sha256sum`).

### 📊 4. Operations, Audit History & Reports
11. **Security Operations Dashboard:**
    - Unified Dashboard calculating a composite 0-100 Security Score.
    - Chart.js donut chart illustrating threat verdict distributions (`Safe`, `Suspicious`, `Malicious`).
    - 7-day activity telemetry graph tracking audit volume over time.
12. **Auditor Accounts, History & Branded PDF Reports:**
    - Flask-Login authentication with Werkzeug password hashing and SQLite persistence.
    - Full audit history supporting category filtering, keyword search, and deletion.
    - Structured JSON export for SIEM ingestion and branded PDF audit reports generated with ReportLab.
13. **Chrome Manifest V3 Extension:**
    - Browser extension in `/extension` that monitors active tab URLs against the local REST API with live color-coded badge alerts (Green/Amber/Red).

## 🚀 Quickstart Guide

### 1. Local Environment Setup
```bash
# Clone or navigate to the repository
cd cybersec-toolkit

# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Train the ML model and export telemetry
python train_model.py

# Launch the application
python run.py
```
Visit `http://localhost:5000` in your web browser.

---

### 2. Running the Test Suite
```bash
# Execute full test suite (35 tests)
pytest -v --cov=app --cov-report=term-missing
```

---

### 3. Running with Docker
```bash
docker compose up --build
```
