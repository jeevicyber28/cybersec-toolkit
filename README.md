An advanced, defensive, and educational cybersecurity web platform and browser extension suite designed for security analysts, developers, and students. It goes far beyond a basic three-tool suite by combining machine learning transparency, zero-knowledge breach analysis, header deconstruction, and gamified phishing awareness.

---

## 🌟 What Makes This Project Different

Unlike traditional basic security tool scripts, **CyberSec Toolkit** delivers an enterprise-grade, defensive, and privacy-respecting platform featuring:

1. **Spot the Phish (Awareness Game):**
   - 10-round interactive quiz drawing from a curated dataset of over 40+ realistic scenarios (URLs, email snippets, and SMS messages).
   - Difficulty progression (`easy`, `medium`, `hard`) with detailed post-answer educational explanations.
   - Dynamic streak multiplier, high score tracking in SQLite, and a tiered badge system (`Rookie`, `Defender`, `Phish Hunter`).
   - Playful CSS celebration animations on perfect scores with strict `prefers-reduced-motion` accessibility support.

2. **Email Journey & Header Analyzer:**
   - Full parser for raw email headers and bodies.
   - Detects spoofing vectors via `From:` vs `Reply-To:` vs `Return-Path:` domain mismatches.
   - Parses cryptographic authentication headers (`SPF`, `DKIM`, and `DMARC` policies).
   - Generates an interactive, human-readable **MTA hop timeline** mapping chronological server hops, intermediate transit delays, and routing IPs.
   - Analyzes deceptive display links (`<a href="evil.com">paypal.com</a>`), social engineering urgency triggers, and dangerous attachment formats (`.exe`, `.scr`, `.zip.exe`).

3. **QR Code Phishing (Quishing) Scanner:**
   - Server-side OpenCV QR matrix decoding supporting uploaded images and noise-resistant adaptive thresholding.
   - Quarantines and displays the decoded URL before assessment with zero auto-redirection.
   - Evaluates the destination payload through the ML phishing classifier.

4. **Password & Breach Checker (Zero-Knowledge):**
   - Implements **k-Anonymity** via Web Crypto API: computes SHA-1 client-side in browser memory and queries only the first 5 hex characters against the Pwned Passwords range API.
   - The plain password and remaining 35 hash characters **never leave the user's browser**.
   - Calculates Shannon entropy in bits, detects keyboard walks and sequential patterns, and estimates brute-force crack time under offline GPU vs online throttled conditions.

5. **Explainable Machine Learning (XAI):**
   - Phishing detector powered by a Random Forest ensemble trained on 16 structural and behavioral URL features.
   - Generates a horizontal bar chart displaying the exact feature contributions and risk weights for every single prediction.
   - Dedicated `/model-info` page generated by `train_model.py` detailing accuracy, precision, recall, F1-score, feature importances, and a confusion matrix.

6. **Combined Safety Score & Activity Telemetry:**
   - Unified Dashboard calculating a composite 0-100 Security Score based on 70% scan hygiene and 30% quiz awareness.
   - Interactive Chart.js donut chart illustrating threat verdict distributions (`Safe`, `Suspicious`, `Malicious`).
   - 7-day activity bar/line graph tracking scan volume and security posture trends over time.

7. **Auditor Accounts, Persistent History & Branded PDF Reports:**
   - Flask-Login authentication with Werkzeug password hashing (`scrypt`/`pbkdf2:sha256`) and SQLAlchemy persistence.
   - Full audit history supporting category filtering, keyword search, and deletion.
   - Structured JSON export for SIEM ingestion and branded PDF audit reports generated with ReportLab.
   - Hardened with Flask-WTF CSRF protection, secure session cookies (`HttpOnly`, `SameSite=Lax`), and strict HTTP security headers (`X-Frame-Options`, `nosniff`).

8. **Manifest V3 Browser Extension:**
   - Chrome/Edge extension in `/extension` that monitors active tab URLs against the local REST API.
   - Displays real-time color-coded badge alerts: Green (Safe), Amber (Warn), Red (Phish) along with numeric threat scores.
   - Popup displays top contributing threat signals and link to full dashboard.

9. **Developer Polish & Infrastructure:**
   - Complete REST API with interactive OpenAPI documentation at `/api/docs`.
   - API Key authentication for external automations and browser extensions.
   - Modern playful pastel cybersecurity design with seamless Light/Dark mode toggle.
   - Production containerization via `Dockerfile` and `docker-compose.yml`.
   - GitHub Actions CI workflow running automated pytest coverage.

## 🚀 Quickstart Guide

### 1. Local Environment Setup
```bash
# Clone or navigate to the repository
cd cybersec-toolkit

# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Train the ML model and export telemetry
python train_model.py

# Launch the application
python run.py
```
Visit `http://localhost:5000` in your web browser.

---

### 2. Running with Docker & Docker Compose
```bash
# Build and run with a single command
docker compose up --build
```
Access the application at `http://localhost:5000`.

---

### 3. Running the Test Suite
```bash
# Execute pytest with coverage report
pytest -v --cov=app --cov-report=term-missing
```

---

### 4. Installing the Chrome Extension
1. Open Google Chrome and go to `chrome://extensions/`.
2. Turn on **Developer mode** in the top right corner.
3. Click **Load unpacked**.
4. Select the `extension/` folder inside this project directory.
5. Click on the extension icon to view live threat telemetry for the active browser tab.

## 🛡️ Defensive & Privacy Principles
- **Zero-Knowledge Password Checks:** Passwords never touch the server. Hashing occurs client-side and only 5 characters of the SHA-1 hash are transmitted.
- **Quarantined Quishing Analysis:** Decoded QR code URLs are presented in read-only sandbox preview boxes and are never auto-opened.
- **Explainable Decisions:** Every machine learning prediction exposes its underlying mathematical and lexical drivers rather than operating as an opaque black box.
- **Confidential Reporting:** Generated audit reports are strictly bound to the authenticated auditor account.
