POST /api/v1/scan-url

Evaluates a target URL against 16 structural features and returns phishing probability with top contributing feature explanations.

REQUEST BODY (JSON)
{
  "url": "http://paypal.com.verify-billing.xyz/auth/login"
}
SUCCESSFUL RESPONSE (200 OK)
{
  "status": "success",
  "url": "http://paypal.com.verify-billing.xyz/auth/login",
  "verdict": "Malicious",
  "verdict_class": "danger",
  "risk_score": 88.5,
  "phishing_probability": 0.885,
  "top_contributions": [
    {
      "feature": "has_https",
      "label": "HTTPS Protocol Implementation",
      "impact": 37.4,
      "direction": "increases_risk"
    }
  ]
}
POST /api/v1/scan-email

Parses raw email headers, SPF/DKIM/DMARC verdicts, server hop timeline, and detects deceptive display links and risky attachments.

REQUEST BODY (JSON)
{
  "raw_email": "Received: from mail.evil.ru...\\nFrom: support@paypal.com\\nSubject: Account Suspended"
}
POST /api/v1/scan-qr

Decodes uploaded QR code server-side and checks payload for malicious destination URLs.

MULTIPART FORM DATA
qr_image: [binary file (.png, .jpg, .webp, .bmp)]
GET /api/v1/pwned-range/{prefix_5}

K-Anonymity range endpoint. Takes strictly the first 5 hexadecimal characters of a SHA-1 hash and proxies the HIBP range database response.

EXAMPLE REQUEST
curl -X GET "http://localhost:5000/api/v1/pwned-range/5BAA6"
GET /api/v1/safety-score

Returns composite safety score (0-100), donut threat distribution, and 7-day activity metrics.
